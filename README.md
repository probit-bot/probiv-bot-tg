## Чем отличаются номер, username и Telegram ID

Номер телефона относится к контактным данным и со временем может перейти другому владельцу. Username пользователь способен изменить, поэтому старые и новые упоминания требуют сверки. Telegram ID имеет числовой формат и обычно используется как более устойчивый идентификатор аккаунта, но он также не отменяет проверку дополнительных признаков.

## Как оценить результат

Сравнивайте несколько независимых полей: ФИО, известный аккаунт, дату актуальности записи и другие разрешённые сведения. Если данные противоречат друг другу, не объединяйте их в один профиль. Отсутствие результата может означать ошибку в запросе или отсутствие доступных связей между записями.
